席位

每个席位是一个已经开着的 coding agent。工作文件夹是那个 agent 能写的地方：执行者一般就是你的项目文件夹；主力兼审方建议给一个专门的空文件夹，这样它对产物只读。用已有的项目文件夹时，取消勾选「替我新建这个空文件夹」（填好路径后页面会自动查一次：文件夹已存在就替你取消勾选）。agent 选「房间内置 Pi」时，这个席位由房间自己托管，不需要另开 agent。
